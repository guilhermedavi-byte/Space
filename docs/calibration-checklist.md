# M9 calibration checklist

For each of 20–30 distinct `meeting_id` calls, compare the UI against the source recording and record: speaker mapping, talk-ratio reasonableness, objection extraction, timeline alignment, CRM outcome and thumbnail usefulness.

Any `fail` requires a mitigation note before launch. Repeated extraction/model errors belong in the known-limitations log and must not be hidden. Playbook patterns remain preliminary until the persisted sample sufficiency supports stronger language.
